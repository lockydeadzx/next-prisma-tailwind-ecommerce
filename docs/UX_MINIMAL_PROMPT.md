# 941store-inspired structure (IA)

## Routes
- `/` — home
- `/catalog` — catalog listing
- `/product/[slug]` — product detail
- `/checkout` — cart + checkout
- `/contacts` — contacts (city/phone)
- `/blog` — articles/landing pages

## Layout (mobile-first)
- Top info row: city link + phone
- Header icons: search, cart, store locator, menu
- Hero banner/slider
- Key promo block (e.g. "product of the day")
- Bottom fixed tabbar: Home, Catalog, Search, Cart

## UI prompt: retail minimalism
- Lots of whitespace, quiet palette, subtle borders/shadows
- Rounded cards and pill buttons, smooth hover/active states
- Clear hierarchy: title -> price -> CTA
- Consistent iconography (but do NOT reuse icons/assets from other sites)

> Note: structure is inspired by 941store, but copy ALL texts, icons, photos, and visuals with your own assets.
